# 📖 Smart Ledger & Personal Khata

A lightweight, secure, and responsive web-based personal ledger tool designed to manage person-wise borrowing, lending, and transaction histories easily. Built with pure HTML, Tailwind CSS, and JavaScript, hosted effortlessly via GitHub Pages.

## ✨ Features

* **Person-Wise Ledgers:** Maintain separate accounts for friends, family, or clients.
* **Smart Language Toggle:** Seamlessly switch between Bengali (বাংলা) and English UI with preference persistence.
* **English Date Format:** Dates are automatically formatted in clean English format (e.g., `26 Oct 2026`) for both new entries and edits.
* **Full CRUD Operations:** Add, edit, delete, and update any transaction amount, date, or note easily.
* **Backup & Restore:** Secure your data locally by exporting or importing `.json` backup files anytime.
* **Local Storage:** All data stays safely in your browser storage.
